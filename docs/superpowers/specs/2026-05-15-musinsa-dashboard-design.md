# 무신사 퍼포먼스 대시보드 — 설계 스펙

**작성일**: 2026-05-15  
**대상 팀**: 퍼포먼스 마케팅  
**목적**: 매일 아침 슬랙 공유용 코멘트를 반자동 생성하는 Streamlit 대시보드

---

## 1. 개요

### 문제

현재 매일 RD(Raw Data) CSV를 열어 수동으로 수치를 확인하고, 파트별 코멘트를 직접 작성한다. 반복 구조가 명확하지만 수치 채우기·포맷 맞추기에 시간이 소요됨.

### 목표

1. RD CSV를 업로드하면 파트별 KPI 지표를 자동 집계
2. 버튼 한 번으로 슬랙 붙여넣기용 코멘트 초안 생성
3. 생성된 코멘트는 텍스트 영역에서 수정 후 복사 가능

### 범위 (이번 스펙)

- **포함**: 무탠유입 파트 전체 (세그먼트 3개 × 상세구분) + 코멘트 생성
- **포함**: 활성고객 파트 기본 KPI + 코멘트 생성
- **추후 확장**: 이탈고객, 20대유입, 뷰티, 풋웨어 탭 (동일 패턴 반복 적용)

## 2. 데이터 소스

| 파트 | 파일 | 필터 조건 |
|---|---|---|
| 무탠유입 | `musinsa_Total_YYYYMMDD~YYYYMMDD.csv` | `종료일자` 컬럼 = `무탠다드유입` |
| 활성고객 | 동일 CSV | `종료일자` = `활성고객` |
| 20대유입 | `무신사_그로스_20대 유입_demo_리포트_YYMMDD.xlsm` | 별도 파일 |

### RD CSV 핵심 컬럼

| 컬럼명 | 용도 |
|---|---|
| `날짜` | 일자 필터 기준 |
| `종료일자` (파트) | 파트 구분 (`무탠다드유입`, `활성고객` 등) |
| `캠페인/구분` | 1차 구분 (무탠유입: `무탠다드맨`, `무탠다드우먼`, `무탠다드통합`) |
| `상세구분` | 2차 구분 (무탠유입: `기획전`, `상시`, `카탈로그`, `캠페인`) |
| `매체` | 채널 (`메타`, `카카오`, `틱톡` 등) |
| `광고비` | 집계 기준 비용 |
| `활성유저수(활성)` | 활성 유저 유입 수 |
| `활성유저수(고활성)` | 고활성 유저 유입 수 |
| `활성유저수(저활성)` | 저활성 유저 유입 수 |

### KPI 계산식

```
활성CPU  = 광고비 / 활성유저수(활성)
고활성CPU = 광고비 / 활성유저수(고활성)
저활성CPU = 광고비 / 활성유저수(저활성)
전일比   = (당일값 - 전일값) / 전일값 × 100
```

## 5. 무탠유입 탭 상세

### 5-1. 1차 구분 (캠페인/구분)

RD의 `캠페인/구분` 컬럼 고유값을 그대로 사용:

| 1차 구분 | 색상 |
|---|---|
| 무탠다드맨 | 🔵 파란 계열 |
| 무탠다드우먼 | 🔴 분홍 계열 |
| 무탠다드통합 | 🟢 초록 계열 |

### 5-2. 2차 구분 (상세구분) — 세그먼트별 집계 규칙

| 세그먼트 | 상세구분 처리 |
|---|---|
| 무탠다드맨 | `기획전` + `상시` → **합산** 표기 / `캠페인` → 별도 표기 |
| 무탠다드우먼 | `기획전` + `상시` → **합산** 표기 / `캠페인` → 별도 표기 |
| 무탠다드통합 | `카탈로그` → 별도 표기 (기획전/상시 없음) |

> `기획전`과 `상시`는 `광고비`, `활성유저수` 모두 합산 후 CPU 재계산.

### 5-3. 테이블 레이아웃

```
세그먼트 / 상세구분 | 광고비 | 활성CPU | 고활성CPU | 저활성CPU | 전일比
─────────────────────────────────────────────────────────────────────
🔵 무탠다드맨       | 합계   |  —     |  —       |  —       |  —
  기획전+상시 합산  | 소계   | XX원   | XX원     | XX원     | ▲/▼
  캠페인            | 소계   | XX원   | XX원     | XX원     | ▲/▼
🔴 무탠다드우먼     | 합계   |  —     |  —       |  —       |  —
  기획전+상시 합산  | 소계   | XX원   | XX원     | XX원     | ▲/▼
  캠페인            | 소계   | XX원   | XX원     | XX원     | ▲/▼
🟢 무탠다드통합     | 합계   |  —     |  —       |  —       |  —
  카탈로그          | 소계   | XX원   | XX원     | XX원     | ▲/▼
```

### 5-4. 전일比 판정 기준

| 변화 | 판정 | 배지 |
|---|---|---|
| CPU -5% 이상 감소 | 개선 | 🟢 ▼ 개선 |
| CPU ±5% 이내 | 동수준 | ⚪ — 동수준 |
| CPU +5% 초과 증가 | 악화 | 🔴 ▲ 악화 |

## 6. 코멘트 생성

### 6-1. 트리거 UI

```
[✍️ 무탠유입 코멘트 생성]              [코멘트 생성 버튼]
세그먼트 3개 × 기획전+상시·캠페인 구분 · 전일 데이터 기준
```

### 6-2. 코멘트 구조 (무탠유입)

```
#무탠유입
- 5월 누적 광고비 XX억 XX만원, 활성CPU XX원, 고활성CPU XX원, 저활성CPU XX원
- 전일 광고비 XX만원, 활성CPU XX원, 고활성CPU XX원, 저활성CPU XX원

[무탠다드맨]
기획전+상시
- 전일 광고비 XX만원, 활성CPU XX원, 고활성CPU XX원, 저활성CPU XX원
- <매체> [소재명] ... (CPU 이상치 소재 자동 감지, 임계 초과 시 포함)

캠페인
- 전일 광고비 XX만원, 활성CPU XX원, 고활성CPU XX원, 저활성CPU XX원

[무탠다드우먼]
기획전+상시
- ...
캠페인
- ...

[무탠다드통합]
카탈로그
- 전일 광고비 XX만원, 활성CPU XX원, 고활성CPU XX원, 저활성CPU XX원
```

### 6-3. 소재 이상치 감지 규칙

- 해당 상세구분 평균 활성CPU 대비 **+50% 이상** → 코멘트에 자동 포함 (주의 소재)
- 해당 상세구분 평균 활성CPU 대비 **-30% 이하** → 코멘트에 자동 포함 (우수 소재)

### 6-4. 출력 UI

- 생성된 텍스트는 `st.text_area`에 표시 (수정 가능)
- **복사** 버튼: `st.code` 또는 JavaScript clipboard API
- **재생성** 버튼: 같은 조건으로 재실행
- 하단 힌트: "수정 후 복사해서 슬랙에 붙여넣으세요"

## 8. 엣지 케이스 처리

| 케이스 | 처리 방법 |
|---|---|
| 전일 데이터 없음 (월요일 등) | "전일 데이터 없음" 표기, 전일比 컬럼 `-` |
| 광고비 = 0인 상세구분 | 테이블에서 회색 처리 또는 제외 (설정 가능) |
| 세그먼트에 해당 상세구분 없음 | 행 자체 미표시 |
| CPU 분모 = 0 (유입 없음) | `—` 표기, 계산 오류 방지 |
| 누적 기간 데이터 없음 | TOTAL 헤더 누적 수치 `—` 처리 |

## 9. 미결 사항 (추후 브레인스토밍)

- 이탈고객 / 뷰티 / 풋웨어 탭 — 1차 구분·2차 구분 컬럼 구조 확인 필요
- 20대유입 탭 — xlsm 파일 구조 별도 파악 필요
- 코멘트 내 매체별 서술 자동화 수준 결정 (완전 자동 vs 수치만 채우고 문장은 수동)
- 누적 기간 집계 범위 (월 누적 vs 주 누적 선택 옵션 여부)
