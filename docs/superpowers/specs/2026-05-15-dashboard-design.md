# 퍼포먼스 마케팅 대시보드 설계

**날짜**: 2026-05-15  
**대상**: 네이버 플러스 스토어 퍼포먼스 팀  
**기술 스택**: Streamlit + Plotly + DuckDB (pandas)

---

## 사용 맥락

| 용도 | 빈도 | 소요 시간 |
|------|------|-----------|
| 아침 브리핑 (전날 성과 확인) | 매일 | 5~10분 |
| 주간 리뷰 (캠페인 조정 근거) | 주 1~2회 | 30분~1시간 |

## 탭 구조 (5탭)

### 탭 1 — 🏠 오늘 요약 (아침 브리핑용)

**목적**: 전날 성과를 5분 안에 파악

**KPI 카드 4개** (전주 같은 요일 대비 증감 % 표시):
- 총 비용
- ROAS (신호등 색상 적용: 🟢 ≥4.0 / 🟡 2.0~4.0 / 🔴 <2.0)
- 가입 CPA (비용 / AF 회원가입)
- AF 커버리지 (AF 가입 / 채널 가입 × 100)

**채널 상태 행**:
- 채널별 ROAS + 신호등 (구글/메타/네이버 브랜드컬러)
- 네이버 브랜드KW(`NVR_CMP_01`) 제외 기준 적용

**주의 캠페인 패널**:
- ROAS < 2.0인 캠페인 자동 표시 (🔴)
- ROAS 2.0~4.0인 캠페인 (🟡)

---

### 탭 2 — 📈 트렌드 (주간 리뷰)

**목적**: "어디에 예산 더 넣을까?" 판단 근거

- 최근 4주 채널별 ROAS 추이 (라인 차트, 채널 브랜드컬러)
- 일별 비용·매출 바차트 + ROAS 보조축
- 평일/주말 분리 토글
- 지표 선택 드롭다운: ROAS / 비용 / 매출 / 가입수 / 구매수

---

### 탭 3 — 🎨 소재 분석 (주간 리뷰)

**목적**: "이 소재 계속 쓸까 말까?" 판단

**소재 타입별 성과**:
- IMG / VID / CRS / TXT 타입별 ROAS·CTR·CVR 가로 바차트

**소재명 파싱** (CLAUDE.md §3-3 기준):
- `_`로 split → 소재타입 / 카테고리 / 시즌 / AB / 버전 컬럼 파생
- 카테고리별, 시즌별 필터

**A/B 판정 테이블**:
- A안 vs B안 ROAS·CTR·CVR 비교
- 샘플 충분 여부 표시 (노출 10만 미달 시 '샘플 부족' 경고)

**소재 랭킹 테이블**:
- 전체 소재 ROAS 내림차순
- 컬럼: 채널, 캠페인, 소재타입, 카테고리, AB, 노출, CTR, CVR, ROAS, CPA

---

### 탭 4 — 📋 보고서 (CSV 다운로드)

**목적**: 엑셀/구글시트 공유용 숫자 + 코멘트

**필터**: 기간 / 채널 / 캠페인목적

**출력**:
1. 집계 테이블 (채널별 또는 캠페인별)
2. 자동 생성 성과 코멘트 (텍스트 복사 버튼)
   - 상위 채널 ROAS 하이라이트
   - 전주 대비 증감 요약
   - 주의 캠페인 언급
3. `📥 CSV 다운로드` 버튼 (utf-8-sig 인코딩)

---

### 탭 5 — 🔗 AF 검증

**목적**: "데이터 믿어도 되나?" 품질 체크

- 채널별 커버리지 (AF 가입 / 채널 가입): 70~90% 정상, 이탈 시 경고
- 채널 보고 vs AF 클릭·전환·ROAS 갭 테이블
- CLAUDE.md §7-3 품질 체크리스트 자동 실행 결과 표시
  - 결측치, 중복, 음수, 이상치 항목별 OK/WARN 표시

## data_loader.py 추가 파생 지표

현재 있음: ROAS, CTR, CVR, CPA, CPM, 소재유형, AF_ROAS

추가 필요:
- `가입_CPA` = 비용 / af_회원가입
- `af_커버리지` = af_회원가입 / 채널_회원가입 × 100
- `소재_카테고리`, `소재_시즌`, `소재_AB`, `소재_버전` (소재명 split)
- `roas_상태` = "양호" / "관찰" / "개선필요" (CLAUDE.md §5-4 기준)
- `전주_동요일_roas` (비교용, 날짜 shift 계산)
